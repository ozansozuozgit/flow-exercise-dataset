# Three-quarter sit-up — clean-room source brief

## Invariants

- Generate one original, source-free 2 × 2 pose sheet with an athletic adult
  performing a three-quarter sit-up. Use no input images.
- Keep a fixed side-facing camera, body proportions, hair, clothing, knees,
  feet, and hand placement. Only the torso angle changes.
- Place one full-body pose in each quadrant with large clear gutters so each
  source pose can be cropped independently.
- Convert each crop to a transparent warm-white silhouette SVG. The generated
  bitmap is only a short-lived source master and is never shipped.
- Treat frame 00 as the coordinate anchor. Preserve a single canvas scale and
  align each later frame's planted-foot edge to frame 00; never independently
  centre or resize animation frames.
- Do not use legacy Flow media, any source GIF, external artwork, text, logo,
  floor, shadow, glow, watermark, or gym environment.

## Frame 00 — start

The athlete lies on their back with both knees bent, feet planted, elbows open,
and fingertips lightly near the ears. The torso is reclined and the spine is
neutral.

## Frame 01 — transition

The athlete has lifted the shoulders and upper back, with the torso visibly
raised above the floor. Keep the knees and feet in their frame-00 positions.

## Frame 02 — end

The athlete has lifted to the high point of the sit-up. The hips remain
grounded, the neck stays neutral, and the elbows remain open without pulling the
head forward.
